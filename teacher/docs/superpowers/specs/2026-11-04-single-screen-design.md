# Single-screen teaching workspace

User requirement: every page stays within one viewport so teachers do not scroll through entire pages.
Retain existing TypeScript app, warm green styling, routes, forms and local records. Compact headers and decorative hero.
Keep navigation, headings, filters and primary actions visible. Bound long data to independently scrollable, keyboard-accessible panels with visible scrollbars and sticky table headings.
Overview uses Today, Insights and Workspace tabs; Today prioritizes weekly activity, schedule and tasks. Secondary summaries remain accessible in Insights.
Approaches: shrinking entire UI harms legibility; clipping content loses actions. Selected: bounded panels and overview tabs, preserving readable text and accessible controls.
Apply at desktop, tablet and mobile sizes; mobile panels can scroll internally. Dialogs retain their own scrolling.
