# Teacher Desk
Build a responsive, standalone teacher workspace covering all 17 requested modules. Use an ivory, forest teal and muted orange visual system, left navigation, compact header, spacious overview cards, chart and agenda. Provide class filters, search, actionable student detail, attendance editing, assignments with resources, quizzes and grading, progress analytics, clearly labeled offline teaching templates, local file storage, timetable, announcements, doubt replies, parent message drafts, leave requests, CSV reports and editable profile.

Chosen defaults: vanilla HTML/CSS/ES modules; browser-local sample data and IndexedDB files. No live MSEC authentication, external AI calls, email delivery or shared database. Existing backend stays untouched. Show demo status and local persistence in product. All created text renders safely. Forms validate required fields. Navigation and dialogs work with keyboard. Public hosting remains owner-private.

Approaches considered: extend existing backend (larger integration and authentication scope); independent demo (chosen to produce reviewable working dashboard immediately). User delegated choices with “yes go for it”.
