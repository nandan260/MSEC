# MSEC Multi-Project Architecture

This repository contains the architecture for three core projects: **Student**, **Teacher**, and **College**.

## 📁 Repository Structure

```
MSEC/
├── student/
│   ├── frontend/         # TypeScript
│   └── backend/          # Python (FastAPI)
├── teacher/
│   ├── frontend/         # TypeScript
│   └── backend/          # Python (FastAPI)
└── college/
    ├── frontend/         # TypeScript
    └── backend/          # Python (FastAPI)
```

## 🛠️ Tech Stack & Dependencies

- **Frontend**: TypeScript (`tsc`), Node.js
- **Backend**: Python 3 (`fastapi`, `uvicorn`, `pydantic`, `python-dotenv`)
